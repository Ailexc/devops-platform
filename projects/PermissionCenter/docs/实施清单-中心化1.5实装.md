## 0. 已裁定口径（本清单开工前提——T0 全部落进方案 v2.1）

1. **body 材料通道【裁定 2026-10-13】**：不做强制"id 进 URL"规范（真实业务做不到、业界亦无此标准）。判定材料位置 = **信封登记制**（POST body 的约定字段如 `meta`，放鉴权用元数据），供材通道按网关形态分：
   - **真实 = APISIX Lua 链内插件**（拦截+转发+判响应）——看得见全请求，整包 body 转给中心、中心按取材声明抠材料（内部量级够用，合规）；演进方向 = 插件就地抠 meta 再传（body 不全过）；
   - **Demo = Traefik**（forwardAuth 只带 path/query 不带体）：path/query 材料走网关链路即判；body 材料（创建 + 存量 POST body-id）走**应用侧带体调用**（fetch-and-bring，与创建参数校验共用同一通道）；
   - **同一套判定契约、同一个信封规范，供材通道按网关能力选，语义无差**——此句进方案 §5/边界表。
2. **凭证豁免**：豁免主语是凭证不是路由——点查/回源优先走**内部地址不过网关**（Demo 即如此，零豁免需求）；确需过网关的豁免必须**绑定中心 M2M 凭证**，裸豁免（只配路径）= 体检阻断。
3. **meta 防伪三道**：变更/删除类不信 meta（按 id 点查权威行，身份只认 JWT）；创建类 meta 是必要材料但伪造被授权集封顶；"判定字段=落库字段"由一次性契约测试钉死。meta 防伪边界成文进 §3.7 信封规范旁。
4. **列表子集校验 = 元组集合语义**：授权范围 = 各策略展开组合的**集合并**（跨策略不打散维度），请求参数元组 ∈ 集合才放行；逐维 ⊆ 仅用于缺参判定；"全量"记通配组合；组合数上限 500（与门禁③同值），超限降档 c；计算异常 fail-closed。
5. **"零调用"限定**：运行期对中心零调用 = 点操作 + 列表主路（创建一次带体调用除外）——§10 边界表同款限定。
6. **"回调"用词**：中心→业务（点查/回源/filter）= 回调；业务→中心（创建/带体校验）= 调用——反向调用不再称"回调"。
7. **投影退役的处置方式【裁定 2026-10-13】**：① A 层投影配套机制（新鲜度状态机/巡检/深对账/force-remote 强一致档）对 CMDB 域**干净移除**——代码与文档同步清干净、不留"退役中"灰态注记（保持干净，防后续文档前后不一致）；仅**数据契约 fields 登记保留**（取材挑字段仍在用）、identity/组同步与 TTL 回收不受影响；② demo 场景 18（巡检）/20（新鲜度）/21（深对账）**随机制下线确认**（R1），场景 19 改造为"删行→点查 data_missing deny"；③ CMDB 判定字段冗余（#8）=**数据同步内部规范既有**，非跨团队卡点——叙事需要时按"内部规范已有"记。

## 三、验收标准（总判据）

1. **点操作**：id 在 path 走网关链路即判（业务零配合）；id 在 body 走带体调用（Demo Traefik 通道）；权威行取材、data_missing deny 可证。
2. **列表**：缺参 deny / 超授权 deny / 正常放行三态 e2e；投影并集漏洞用例必拒；档 a 系统零登记零影响。
3. **动作码**：两应用全量导入路由表；运行期纯查表（含静态段优先用例）；变更阻断+迁移可演示。
4. **投影退役（干净移除）**：CMDB 域判定日志零投影读；同步管道（CMDB worker/巡检/深对账/force-remote）代码与配置删净；**全仓残留引用清零**（方案 v2.1 决策记录的历史表述除外）；身份同步与 TTL 回收不受影响。
5. **体检**：六类坏配置全被阻断；裸豁免阻断生效。
6. **回归**：`go build ./... && go vet ./... && go test ./...`、前端 build、demo 全量场景+硬断言、reset 后复跑全绿。
