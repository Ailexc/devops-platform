## 一段话说清这次升级

> 老架构：网关判接口级 + 中心判数据级（投影），权限中心重、与上游耦合。
> 新架构：**网关只认证，鉴权全部下沉业务侧**——SDK 中间件收口 + 旁挂 Agent 纯判定 + **声明驱动取材**（数据不出业务系统）；中心只管**策略生命周期**（申请/审批/版本/到期/审计）与**按 app 打包分发**。
> 收益：投影退役、新鲜度税消失、中心 QPS 摊掉、自循环破除（人归身份源）；代价：撤销传播窗口（秒~分钟）、防绕过靠契约+审计（企业内部可强制）。
