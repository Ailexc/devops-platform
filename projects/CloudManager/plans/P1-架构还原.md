# P1 · 架构还原（最小闭环）

**目标**：跑通"申请主机 → 审批 → 自动执行 → CMDB 回写 → 列表可见"的端到端最小闭环。
**验收**：登录后可在页面完成一次完整的主机申请与状态管控操作。
**状态**：⏳ 待审查
