一、选型前提（硬约束）

  • 面向企业内网部署，单机 / 小型集群即可。
  • 需快速演示完整业务闭环，降低基建成本。
  • 架构上需与真实项目（Java Spring Boot）保持同构。

二、选型建议

领域技术理由
前端Vue 3 + TypeScript + Vite + Ant Design Vue组件丰富、生态成熟、类型安全
后端Django 4.2 + DRF + SimpleJWT快速建模、自带 Admin、认证完善
数据库MySQL 8（生产）/ SQLite（本地）稳定通用，支持 JSON / 多表
消息队列RabbitMQ（真实）→ 本 Demo 用 Mock Provider 异步异步长任务解耦
部署Docker Compose + Nginx一键起多服务，便于演示

三、关键选型理由

前端：Vue 3 + Ant Design Vue

企业级组件全（表格 / 表单 / 图表联动），配合 ECharts 实现成本大屏与依赖图谱。

后端：Django REST Framework

ORM 建模高效、DRF 序列化 + 视图集快速出 API、自带 JWT 认证与权限体系，适合快速交付 Demo。

四、Mock 策略（Demo 关键设计）

  • 数据全 Mock：账号、资源、账单、建议均由 seed 脚本生成，贴近真实分布。
  • Provider Mock：云操作由 Mock Provider 模拟执行 + 回写 CMDB，闭环完整。
  • 成本模拟采集：seed_metrics 写 CPU / 内存指标，供规则引擎检测。

五、暂缓 / 排除项

  • 真实云 SDK 对接（Demo 阶段 Mock Provider 足够）。
  • 消息队列 / 缓存中间件（异步用任务表模拟）。
  • 复杂工作流引擎（工单状态机简化实现）。
