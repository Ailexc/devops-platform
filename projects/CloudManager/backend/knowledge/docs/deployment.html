一、部署架构

浏览器 → Nginx(前端静态 + 反代) → Django Backend(DRF) → MySQL 8

docker-compose.prod.yml 编排：frontend（Nginx）、backend（Django + uvicorn/gunicorn）、db（MySQL 8）。

二、快速开始

  1. 构建后端镜像（含 seed 命令）：docker compose -f docker-compose.prod.yml build backend
  2. 构建前端：cd frontend && npm run build（dist 挂载进 Nginx）
  3. 启动：./deploy.sh 或 docker compose up -d
  4. 访问：前端 http://cloud-manager-nginx.orb.local · 后端 http://cloud-manager-backend.orb.local/api/

三、关键配置

  • MySQL 启动参数需加 --sort-buffer-size=16M，避免大批量排序触发 1038 错误。
  • entrypoint.sh 按序执行 migrate + seed 数据（账号 / 资源 / 成本 / 规则 / 知识库）。
  • 前端 dist 由 Nginx 挂载，重构建后自动生效。

四、常见问题

  • 接口返回非 JSON：后端容器未就绪，等待后重试（grep "Listening at" 确认）。
  • 后端改动不生效：需 build backend 重建镜像（代码 COPY 进镜像）。
  • 数据库错误：检查 MySQL 容器与卷。
