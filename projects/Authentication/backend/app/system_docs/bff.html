什么是 BFF

BFF（Backend for Frontend，面向前端后端）是一种架构模式：为前端单独提供一个专属后端，前端只跟它对话，由它去调用下游服务、处理认证、聚合数据。

为什么需要它？因为前端（尤其 SPA）暴露在浏览器里，放不下机密（client_secret、私钥）；而直接让前端对接一堆微服务又会造成耦合。BFF 把"前端想要的样子"和"后端真实能力"之间做一层适配：

  • 藏机密：client_secret、令牌只存在 BFF 服务端；
  • 简化前端：前端只调自己的 BFF 接口，不用懂 OAuth/OIDC 细节；
  • 聚合数据：一个页面要多个服务的数据时，BFF 统一编排。

为什么 OIDC 场景必须有 BFF

OIDC 授权码 + PKCE 流程中，client_secret 只能放在后端（纯前端放 secret 等于把门钥匙贴门上）。门户要作为 OIDC 客户端接入认证中心，就必须有一个后端来：

  1. 生成 PKCE code_verifier / code_challenge 与 state / nonce；
  2. 接收授权码回跳并校验 state；
  3. 用 code + code_verifier + client_secret 到令牌端点换 token；
  4. 把用户身份包装成前端可用的会话。

这个"门户专属后端"就是门户 BFF。它是本项目 OIDC 标准化的关键一环：门户 = SPA（前端） + BFF（OIDC 客户端），二者合起来才是一个完整的 OIDC 客户端。

本系统的 BFF 实现

门户 BFF 由后端 portal.py 实现（路由前缀 /portal），主要端点：

端点作用
GET /portal/oauth/login生成 PKCE 挑战值 + state + nonce，302 跳认证中心 /authorize
GET /portal/oauth/callback接收授权码回跳，校验 state，换 token，建立 HttpOnly 会话，302 回门户
GET /portal/api/me从门户会话解析当前用户（SPA 恢复登录态用）
POST /portal/api/logout清门户 BFF 会话（IdP 会话由 /oauth/logout end_session 负责）

会话用 HttpOnly Cookie（portal_session） 保存：浏览器 JS 读不到，只能由同源请求自动携带。SPA 请求 /portal/api/me 即可无感恢复登录态。

# 一次完整登录的时序（浏览器视角，全部经 nginx 同源反代）
浏览器       门户SPA        门户BFF       认证中心(IdP)
  │ 点击登录    │             │              │
  │──────────▶│  /portal/oauth/login      │
  │           │             │─────────────▶│  /oauth/authorize?client_id&PKCE&state&nonce
  │           │             │◀─────────────│  302 登录页
  │◀───────────────────────────────────────│  用户输入账密
  │           │             │◀─────────────│  302 回 callback?code=&state=
  │           │             │  code+verifier+secret 换 token
  │           │             │─────────────▶│  /oauth/token
  │           │             │◀─────────────│  id/access/refresh token
  │           │             │  建立 HttpOnly 会话
  │◀──────────│  302 回门户  │             │
  │  /portal/api/me 无感恢复用户            │
本项目落地：Demo 中门户 BFF 与认证中心（IdP）同进程部署（都是 auth-backend），便于演示；生产上 BFF 应独立成服务，甚至直接用成熟的 OIDC 客户端库，这是已明确的演进方向。

小结

  • BFF = 面向前端专属后端，藏机密、简化前端、聚合数据。
  • OIDC 场景必须有 BFF：client_secret 只能放后端。
  • 门户 = SPA + BFF 组合，登录态走 HttpOnly Cookie 会话。
