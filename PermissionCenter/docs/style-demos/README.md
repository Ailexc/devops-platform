# Permission Center — 美术风格方案（Demo 对比）

当前系统为**黑白单色 · 直角 · 无层次**的极简风格，观感朴素。
以下提供 4 套参考业内实现的风格 Demo，用浏览器打开对应 HTML 即可对比。

## 方案一览

| 方案 | 文件 | 参考产品 | 风格定位 | 特点 |
|------|------|----------|----------|------|
| **A. 云原生企业蓝** | `demo-a-cloud-blue.html` | Cloudflare / Okta / Grafana | 清爽 · 专业 · 安全可信 | 亮色、品牌蓝、圆角卡片、彩色语义标签、柔和阴影 |
| **B. 深色 Linear 风** | `demo-b-dark-linear.html` | Linear / Vercel / GitHub | 高级 · 专注 · 技术感 | 深色、紫蓝点缀、细腻边框、等宽数据、精致微交互 |
| **C. 现代 SaaS 渐变玻璃** | `demo-c-glass-saas.html` | Stripe / Notion / 新 AI 产品 | 现代 · 活力 · 品牌化 | 渐变背景、玻璃拟态卡片、大圆角、多彩标签 |
| **D. 精修极简黑白** | `demo-d-refined-mono.html` | 现有风格的精修版 | 克制 · 工具感 | 保留黑白基调，加入圆角、层次、SVG 图标、更好的间距 |

## 落地说明

- 技术栈为 **Vue 3 + Element Plus**，所有方案均为纯 CSS 变量覆盖 `frontend/src/styles/theme.css`，
  无需改组件结构即可切换。
- 每套方案都包含：完整 CSS 变量（亮/暗双主题）、Element Plus 覆盖变量、导航侧边栏、工作台、
  权限市场卡片、状态标签的示例。
- 选好后我会把对应主题落地到 `theme.css`，并把页面中的 emoji 图标替换为 SVG。

## 建议

- **要"专业可信、易于阅读"** → 选 A（云原生蓝），最贴近企业 IAM 产品的通用做法。
- **要"高级感、适合深度使用/夜间"** → 选 B（深色 Linear 风）。
- **要"现代醒目、品牌感强"** → 选 C（渐变玻璃拟态）。
- **要"保持现有极简调性但更精致"** → 选 D（精修黑白）。
