一、总体 ER 概览

四大模块：CMDB（资源） / 工单系统（流程） / 权限审计 / 成本（账单）。

二、CMDB 模块

cmdb_cloud_account 云账号表

云厂商、账号名、AK/SK 引用、区域列表、状态。

cmdb_resource 统一资源表（多态建模核心）

字段说明
resource_typeinstance / database / cache / load_balancer ...
metadataJSON 扩展字段（规格 / IP / 配置）
provider_type / region / account云厂商、区域、归属账号
application / department归属标签（业务视角）
status运行中 / 已停止 / 异常

cmdb_resource_relation 资源关系表

source_id → target_id + relation_type，支撑依赖图谱。

cmdb_resource_change 变更历史表

每次操作留痕：操作人、类型、前后 diff、工单号。

cmdb_application 应用表

应用归属组织、环境（dev / prod）、预算（budget_amount）。

三、工单系统模块

  • ticket_order：单号 WO+日期+序列、类型（create/start/stop/change/delete/relation_change/apply_quota）、状态 8 种流转、请求参数、关联资源。
  • ticket_approval：审批人、意见、时间，支持多人 / 驳回重提。
  • ticket_task：自动化任务（执行 Provider / 回写 CMDB）。

四、成本模块

  • fin_cost_bill：账单（云厂商 / 账号 / 月份 / 总额）。
  • fin_cost_item：成本明细，含 department / application 分摊标签（Cost Allocation Tag）。
  • fin_budget：部门 / 应用预算。

五、索引与性能要点

  • 资源表按 (provider_type, status) 建索引。
  • 成本明细按 (bill_id, department, application) 建组合索引，支撑分摊聚合。
  • 变更历史按 resource_id + created_at 索引，分页查询。
