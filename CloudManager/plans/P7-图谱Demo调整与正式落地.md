## 二、后端改动

### 2.1 资源归属标识（自建 vs 云资源）

- [ ] `Resource.managed_by` 字段：`cloud`（云托管）/ `self`（自建）/ `hybrid`，默认 `cloud`
- [ ] 迁移 + 序列化器暴露 `managed_by` / `managed_by_display`
- [ ] 种子数据填充：RDS/Redis/Kafka/S3/网关/安全组/EC2 = `cloud`；自建中间件/自建实例 = `self`

### 2.2 待生效变更接口（持久化"审批中"状态）

- [ ] `GET /api/cmdb/graph/pending-changes/?environment_id=`：返回该环境下**未完成**的 `relation_change` 工单中的 changes（含工单号/状态）
- [ ] 前端据此在刷新后仍能看到「审批中」的虚边，工单成功后自动消失并刷新真实图谱
- [ ] 关系变更工单审批通过后（现有 `apply_relation_changes`）保持不动，落库即生效

### 2.3 其他

- [ ] 环境图谱接口补充：资源节点 meta 增加 `managed_by`；服务节点 meta 已有实例信息（保持）
- [ ] 无新增表；仅字段 + 接口

## 三、前端改动（GraphDemo 调整 + 抽成正式组件）

### 3.1 整体缩放（反馈 1）

- [ ] 区域背景从 `graphic` 元素改为**图内底衬节点**（大透明圆角矩形，参与 roam 变换）
- [ ] 底衬节点：`silent: true`、无 tooltip/无点击、绘制顺序在方块之前（z 层在最底）
- [ ] 区域标签同样作为底衬节点的 label，随图缩放
- [ ] 验证：放大/缩小/平移时，方块与区域背景始终一体

### 3.2 视觉风格统一（反馈 2）

- [ ] 配色规范：三区域低饱和浅底 + 统一强调色；节点边框/阴影/圆角统一（8px 圆角、柔和阴影）
- [ ] 方框内部排版：图标 + 名称 + 关键字段，字号/行高统一，弱化次要信息
- [ ] 连线：曲线曲率统一、软依赖虚线 + 降低透明度，箭头更小更精致
- [ ] 图例卡片化（节点图例 + 线型图例分两行），悬浮样式现代化（白底圆角卡片 + 阴影）
- [ ] 整体留白与间距调整，避免贴边

### 3.3 实例下钻（反馈 3）

- [ ] 服务抽屉「实例清单」表格增加"查看"操作；点击行/按钮 → 打开该实例的**资源抽屉**
- [ ] 实例资源抽屉复用现有资源抽屉（基础信息 / 依赖关系 / 影响面 / 变更历史）
- [ ] 图上方框内的实例数徽标可点击展开实例浮层（可选，先做抽屉内下钻）

### 3.4 服务依赖的上下游标记（反馈 4）

- [ ] 服务抽屉「依赖资源」Tab 改为分组展示：
  - **下游依赖**（本服务依赖的资源，如 数据库/缓存/消息）→ 标签「下游」
  - **上游调用**（依赖本服务的对象，如 网关/前端）→ 标签「上游」
  - **相互通信**（双向，如 前端↔后端）→ 标签「通信」
- [ ] 依赖方向从图的边方向推导（出边=下游依赖，入边=上游调用）
- [ ] 图上点击服务节点时，高亮该服务相关的边（当前已支持 emphasis adjacency，补上方向颜色：上游青/下游橙）

### 3.5 自建/云资源标识（反馈 5）

- [ ] 方框内增加角标：`☁️ 云` / `🏠 自建`（依据 `managed_by`）
- [ ] 资源抽屉「基础信息」增加"资源归属"字段
- [ ] 图例增加归属说明

### 3.6 编辑变更实时预览（反馈 6）

- [ ] 编辑模式下新增/移除/变更依赖后，**立即渲染到图上**：
  - 新增依赖：虚线灰蓝边 + 两端节点右上角「待接入」角标
  - 移除/变更：原边变红色删除态或标注目标强度
- [ ] 点击"待接入"边 → 抽屉显示「未接入 / 审批中」状态 + 关联工单号 + 「去工单查看」
- [ ] 提交后：pending 边保留并关联工单；轮询工单状态，审批通过后刷新真实图谱、虚边消失
- [ ] 刷新页面后通过 `pending-changes` 接口恢复"审批中"视图

### 3.7 组件化（为正式落地做准备）

- [ ] 将 Demo 中的渲染逻辑抽成 `components/TopoCanvas.vue`（props：nodes/edges/options；事件：node-click/edge-click/zoom）
- [ ] 将抽屉抽成 `components/ResourceDrawer.vue`（资源）/ `components/ServiceDrawer.vue`（服务）/ `components/RelationDrawer.vue`（边）
- [ ] 编辑模式与变更草稿抽成 composable：`useRelationEditor`
