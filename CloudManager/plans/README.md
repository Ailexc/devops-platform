# 开发计划 · 总览

> 本计划基于 `docs/` 设计文档制定，**供审查确认后执行**。
> 状态：⏳ 待审查

---

## 一、已确认的决策

| 项 | 决策 |
|---|---|
| 架构 | 前端 → 后端 → 工单系统 → CMDB（还原真实项目四层骨架） |
| 后端 | Python **Django** + DRF + SimpleJWT + MySQL + Redis + Celery |
| 前端 | **Vue 3** + TypeScript + Vite + Pinia + Ant Design Vue + ECharts |
| 前端方案 | 控制台布局（顶部全局栏 + 左侧导航 + 多页签工作区）+ **配置驱动渲染** |
| 多云适配 | `CloudProvider` 抽象 + AWS / 阿里云 / Mock Provider（插件化） |
| 权限 | 本地简化实现（登录/角色/权限点），架构按"**可接入统一权限中心**"设计（鉴权可插拔） |
| 审计 | 只做**提单记录**（工单结果/审批/执行），**预留统一审计平台事件上报接口** |
| Mock 策略 | Mock Provider 提供模拟云，无真实云账号也可完整演示 |
| 部署 | Docker Compose 一键启动 |

## 二、阶段总览

| 阶段 | 主题 | 核心交付 | 验收标准 |
|---|---|---|---|
| **P1** | 架构还原 | Django+Vue 骨架、Mock Provider、工单状态机、计算模块 | 端到端"申请→审批→执行→回写"最小闭环 |
| **P2** | 多云适配 | 云适配层 + AWS/阿里云/Mock + 统一资源模型 | 一套页面管理多朵云 |
| **P3** | 业务闭环 | 服务目录、权限体系、提单审计、CMDB 深化 | 角色隔离 + 审计留痕 + 资源拓扑 |
| **P4** | 亮点冲刺 | 成本中心、智能资源建议、演示打磨 | 完整可对外演示 |

## 三、里程碑

- **M1**（P1 完成）：最小闭环可演示，可作为基础版本
- **M2**（P2 完成）：真正"多云"，架构亮点成型
- **M3**（P3 完成）：企业级能力齐全
- **M4**（P4 完成）：面试级完整 Demo

## 四、目标目录结构

```
cloud_manager/
├── backend/                  # Django 项目
│   ├── config/               # settings / urls
│   ├── apps/
│   │   ├── accounts/         # 用户·角色·权限（本地简化 + 接入预留）
│   │   ├── cmdb/             # 资源·关系·变更·同步
│   │   ├── ticket/           # 工单·审批·任务·执行器
│   │   ├── provider/         # 云适配层（core / aws / aliyun / mock）
│   │   ├── catalog/          # 服务目录（P3）
│   │   └── cost/             # 成本（P4）
│   └── manage.py
├── frontend/                 # Vue3 项目
│   └── src/
│       ├── layouts/          # 控制台布局（顶栏 / 侧栏 / 页签）
│       ├── configs/          # 资源模块配置（Schema）
│       ├── components/       # ResourcePage 等通用组件
│       ├── views/            # 工作台 / 资源 / 工单 / 成本 / 审计
│       ├── api/              # 请求封装
│       ├── directives/       # v-permission
│       └── stores/           # Pinia
├── docs/                     # 设计文档
├── plans/                    # 开发计划（本目录）
└── docker-compose.yml
```
