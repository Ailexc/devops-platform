## 5. 端口分配流程（下次拉起 / 新增应用时）

1. **查表**：确认目标端口在 8088~8099 范围内且未被占用（见 §1/§4）。
2. **四步修改**（以新增系统 `foo` 为例）：
   - `infra/gateway/traefik.yml`：加 `entryPoints.web-foo: ":<port>"`
   - `infra/gateway/docker-compose.yml`：加 `- "<port>:<port>"`
   - `infra/gateway/dynamic/routes.yml`：加 router（`Host(114.55.244.220)` + `entryPoints: [web-foo]`）+ service
   - `deploy/cloud/.env.cloud`：加 `APP_URL_FOO=http://114.55.244.220:<port>`
3. **目标容器加入 `devops-net`**（compose `networks: [default, devops-net]`），否则网关无法路由。
4. **更新本文档** §1 表格。
5. 部署：`make gateway-up` + 重建目标服务 + `--force-recreate auth-backend`（同步 DB home_url）。
