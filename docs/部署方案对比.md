# DevOps 平台合集 —— 免费 / 低成本部署方案横向对比

> 调研日期：2026-08-16 · 依据：各平台官方定价/文档
> 目的：对比「静态展示页」与「7 个全栈系统 + PG + Redis」的所有可行承载方式，给出推荐组合。

## 一、静态展示页（showcase）托管 —— 全免费，随意选

| 平台 | 免费额度 | 特点 | 国内访问 |
|------|----------|------|----------|
| GitHub Pages | 无限、1GB | 零配置、`username.github.io` | 一般 |
| Cloudflare Pages | 无限请求、全球 CDN | 速度快、可自定义域名 | 免费版国内时快时慢 |
| Vercel | 无限静态（Hobby） | Edge 网络、预览友好 | 不稳定 |
| Netlify | 无限静态 | 简单 | 不稳定 |

> 展示页是**单文件纯静态**，这几个平台都能白嫖。若非常在意国内访问速度，可把展示页也放阿里云服务器上（见下）。

### 2.2 关键解读

- **真正"免费且够用"的服务器**：只有 **Oracle Cloud Always Free（ARM）** 和 **阿里云试用/低配**。其余 PaaS 免费档（Render/Railway/Koyeb/Fly）要么额度苛刻、要么已实质收费。
- **免费托管数据库/缓存**：**Neon（PG，分支=快照）** 与 **Upstash（Redis，有持久化）** 是数据层免运维的最优补位；Supabase 免费 PG 次之（会暂停）。
- **阿里云是你手头现成的牌**：你的 7 个系统全部 Docker 化，在一台服务器上 `docker compose up` 全家桶 + Traefik 统一网关即可整体上线，且与我们规划的"统一构建/部署/重置"天然契合（数据在自己手里，`make reset` 随时还原）。

## 三、推荐组合

### ✅ 首选：展示页静态 + 全家桶跑阿里云（混合）

```
面试官/访问者
    │
    ▼
[静态展示页]  showcase ──GitHub Pages / Cloudflare Pages（免费）
    │  CTA「进入统一门户」
    ▼
[阿里云服务器]  统一门户 + 7 系统 + 统一 PG + Redis
    │  Docker Compose + Traefik 统一网关（HTTPS）
    ▼
各系统独立路径 /subdomain 访问
```

- **展示页**：放 GitHub Pages / Cloudflare Pages（免费、静态、全球 CDN）。
- **统一门户 + 全家桶**：跑在阿里云轻量服务器（试用期 0 成本，续费 ¥24–40/月）。
- **跳转方式**（按备案情况二选一）：
  - 无备案：`http://<公网IP>:<端口>`（如 `:8080`）直接访问，无需备案；
  - 想用域名 + 80/443：大陆实例需先做 **ICP 备案**（约 1–2 周，阿里云后台免费办理）；或买**香港区**实例免备案。
- 优点：一个 Compose 全拉起、统一管理/重置完全可控、不受"免费额度"束缚、面试演示稳定；缺点：要自己装 Docker/安全组/（可选）备案。

### 🥈 免费替代：Oracle Cloud Always Free 当 VPS

- 若不想花钱或阿里云试用到期：在 OCI 免费 ARM VM 上跑**同样的** Docker Compose 全家桶。
- 成本 $0、配置足够（常开约 2C/12GB）；但要绑信用卡注册、可能遇 A1 容量不足、且有被回收风险、国内访问走海外链路偏慢。

### 🥉 数据层免运维补位（可叠加）

- 服务器只跑应用，数据层用 **Neon 免费 PG（分支做快照还原）** + **Upstash 免费 Redis**，减少本地数据备份/还原负担。
- 缺点：受 0.5GB / 256MB 限制，种子数据需精简。

### 4️⃣ 纯免费 PaaS（Render/Railway）

- 只适合"一个月内集中面试、接受各种限制"的短周期场景（详见《统一部署与管理方案》）。

## 四、我的建议

1. **静态展示页**：先放 **GitHub Pages**（零配置），上线后如果国内访问慢再切 Cloudflare Pages 或直接搬上阿里云。
2. **全家桶主承载**：**阿里云轻量服务器**（试用期先用起来，成本为 0）。一台机器 `docker compose up` 全家桶 + Traefik，配合我们规划的顶层 `Makefile`（统一构建/部署/重置）——这是**工程上最顺、演示最稳、面试最加分**的路线。
3. **可选优化**：把 **Neon（PG 分支快照）** 作为"演示数据快照还原"的演示亮点（面试可讲"利用 Neon 分支实现秒级环境重置"）；用 **Upstash** 做跨系统共享缓存。
4. 若最终零预算诉求很强 → 退到 **Oracle Always Free ARM**（同套 Compose），接受海外访问偏慢与稳定性风险。

> 一句话：**"展示页白嫖 + 全家桶跑自己服务器（阿里云/Oracle 免费）"** 是性价比和可控性的最优解；纯 PaaS 免费方案只适合短周期应急。
