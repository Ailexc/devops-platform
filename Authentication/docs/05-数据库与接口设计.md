# 统一认证中心 — 数据库与 API 设计

## 一、数据库设计（SQLite / PostgreSQL 可切换）

### 用户表 `users`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增 |
| username | TEXT UNIQUE | 登录名（唯一） |
| password_hash | TEXT | bcrypt 哈希（仅本地身份源使用；LDAP/Okta 用户可为空） |
| display_name | TEXT | 显示名 |
| email | TEXT | 邮箱 |
| department | TEXT | 部门 |
| phone | TEXT | 手机号 |
| is_active | BOOLEAN | 是否启用 |
| is_admin | BOOLEAN | 是否管理员（可管理用户/应用） |
| source | TEXT | 默认身份源（local/ldap/okta） |
| created_at / updated_at | DATETIME | 时间戳 |

### 应用注册表 `app_registrations`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增 |
| app_id | TEXT UNIQUE | 应用标识（如 `task-manager`） |
| name | TEXT | 应用名（门户展示） |
| description | TEXT | 描述 |
| icon | TEXT | 图标（antd 图标名 / URL） |
| home_url | TEXT | 门户点击后跳转地址 |
| sso_type | TEXT | sso 类型：`token`(携带JWT) / `oidc`(授权码) |
| client_id / client_secret | TEXT | OIDC 对接用（预留） |
| enabled | BOOLEAN | 是否在门户展示 |
| sort_order | INTEGER | 排序 |
| created_at / updated_at | DATETIME | 时间戳 |

### 认证日志表 `auth_logs`（可选，审计用）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增 |
| username | TEXT | 登录名 |
| source | TEXT | 实际认证来源（local/ldap/okta） |
| success | BOOLEAN | 是否成功 |
| ip | TEXT | 来源 IP |
| detail | TEXT | 失败原因等 |
| created_at | DATETIME | 时间 |

## 二、JWT 载荷设计

```
{
  "sub": "12",                       # 用户 ID
  "uid": "zhangsan",                 # 登录名
  "name": "张三",
  "email": "zhangsan@devops.com",
  "department": "研发部",
  "source": "ldap",                  # 实际认证来源
  "iss": "https://auth.{domain}",    # 签发者
  "aud": "devops-portal",            # 受众
  "iat": 1690000000,
  "exp": 1690003600,                 # 1 小时
  "jti": "uuid"                      # JWT ID，用于刷新/撤销
}
```

- 签名算法：**RS256**（非对称），公钥经 `/.well-known/jwks.json` 发布
- 业务系统用公钥验签即可，无需回源

## 三、API 设计

### 认证接口 `/api/auth/*`

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/auth/login` | 用户名密码登录 → 身份源降级链 → 返回 JWT + 用户 |
| POST | `/api/auth/refresh` | 用 refresh_token 换新 access_token |
| POST | `/api/auth/logout` | 登出（撤销 refresh token） |
| GET | `/api/auth/me` | 当前登录用户信息（门户/个人中心用） |
| POST | `/api/auth/change-password` | 修改密码 |
| GET | `/api/auth/sso-url` | 获取某应用的 SSO 跳转地址（带 JWT） |
| GET | `/api/auth/verify` | **网关 forwardAuth 用**：校验 Bearer JWT，返回 200/401 + 用户头 |

### 应用注册表 `/api/apps/*`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/apps` | 门户应用广场列表（仅 enabled） |
| POST | `/api/apps` | 新增应用（管理员） |
| PUT | `/api/apps/{id}` | 更新应用 |
| DELETE | `/api/apps/{id}` | 删除应用 |

### 用户管理 `/api/users/*`（管理员）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/users` | 用户列表 |
| POST | `/api/users` | 新增用户（本地身份源） |
| PUT | `/api/users/{id}` | 更新用户 |
| DELETE | `/api/users/{id}` | 删除/禁用用户 |

### 系统 `/api/system/*` 与公钥

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/system/health` | 健康检查 |
| GET | `/api/system/providers` | 当前身份源状态（可用性，运维/演示用） |
| GET | `/.well-known/jwks.json` | JWT 公钥（JWKS） |

### 统一鉴权约定（forwardAuth）

- 请求头 `Authorization: Bearer <JWT>`
- 网关放行时注入：`X-Auth-User`（用户ID）、`X-Auth-Username`、`X-Auth-Name`、`X-Auth-Source`
- 业务后端从请求头取身份，无需解析 JWT
