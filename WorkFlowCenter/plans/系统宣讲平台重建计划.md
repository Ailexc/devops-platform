## 一、现状分析

### 当前实现

| 项目 | 说明 |
|------|------|
| 组件 | `SlideEngine.vue`（单文件，~200 行） |
| 数据 | `presentation-slides.js`（纯文字/截图/代码幻灯片） |
| 类型 | hero、text、image、code 四种静态页面 |
| 交互 | 键盘翻页、自动播放、场景选择器 |

### 核心问题

| # | 问题 | 影响 |
|---|------|------|
| 1 | **没有模拟真实 UI** | 像 PPT 而不是产品演示，观众无法感知实际操作体验 |
| 2 | **没有步骤旁白** | 缺少解说词，演示者需要背诵功能亮点 |
| 3 | **没有角色标识** | 不清楚当前演示的是谁的视角 |
| 4 | **没有焦点高亮** | 无法引导观众注意力到关键区域 |
| 5 | **布局简陋** | 单栏布局，信息密度低 |
| 6 | **没有场景目录** | 无法快速跳转到感兴趣的场景 |

## 五、核心数据结构

### 类型定义（presentation.ts）

```typescript
export interface Step {
  /** 对应的模拟组件名 */
  component: string
  /** 步骤标题（可选，覆盖默认） */
  title?: string
  /** 高亮焦点 */
  focus?: string
  /** 旁白解说词 */
  narration: string
  /** 核心卖点 */
  highlight?: string
  /** 过渡动画 */
  animation?: 'slide-left' | 'slide-right' | 'fade' | 'pop-in'
}

export interface Scene {
  id: string
  title: string
  description: string
  /** 场景主题色 */
  themeColor: string
  /** 演示角色 */
  role: string
  /** 角色标签 */
  roleLabel: string
  /** 步骤列表 */
  steps: Step[]
}
```

## 六、组件设计

### 1. PresentationHub（目录页）

- 渐变背景 + 居中标题 + 统计徽章
- 场景卡片网格（2 列）
- 悬停效果：边框变色 + 阴影 + 上移
- 键盘快捷键提示

### 2. PresentationPlayer（播放器）

**三栏布局**：

| 区域 | 宽度 | 内容 |
|------|------|------|
| 左侧步骤栏 | 200px | 步骤列表，可点击跳转 |
| 中间模拟区 | flex:1 | 动态组件渲染 |
| 右侧信息栏 | 300px | 旁白 + 卖点 + 导航按钮 |

**顶部工具栏**：返回按钮 + 场景标题 + 步骤计数 + 角色徽章

**底部进度条**：4px 高，带进度点和场景主题色

### 3. 模拟屏幕组件

每个组件是**纯前端静态模拟**，不调用真实 API：
- 使用硬编码数据模拟真实 UI
- 通过 `focus` prop 控制高亮区域
- 使用 CSS 过渡实现视觉聚焦
- 异步组件加载，不影响首屏

### 4. 组件清单

| 组件 | 模拟内容 | focus 选项 |
|------|---------|-----------|
| LoginSim | 登录页，用户选择器 | - |
| DashboardSim | 工作台，统计卡片 | 'stats' / 'shortcuts' |
| FlowDesignerSim | 流程设计器 | 'canvas' / 'nodeConfig' / 'palette' |
| FormDesignerSim | 表单设计器 | 'schema' / 'preview' |
| TaskDetailSim | 任务办理页 | 'approval' / 'autoExecute' / 'timeline' |
| CapabilitySim | 能力执行结果 | 'actions' / 'output' |
| ApiDemoSim | API 调用演示 | 'curl' / 'response' |
| ApplySim | 发起申请页 | 'form' / 'submit' |
| SummarySim | 总结页 | - |

## 七、交互规范

### 键盘快捷键

| 按键 | 功能 |
|------|------|
| `←` | 上一步 |
| `→` / `Space` | 下一步 |
| `ESC` | 返回目录 |

### 过渡动画

| 方向 | 动画 |
|------|------|
| 前进 | slide-left（左滑进入） |
| 后退 | slide-right（右滑进入） |
| 场景切换 | fade（淡入淡出） |

### 自动播放

- 默认关闭，点击播放按钮开启
- 每 4 秒自动切换步骤
- 最后一步自动停止

## 十一、与现有实现的对比

| 维度 | 当前实现 | 新实现 |
|------|---------|--------|
| 架构 | 单文件 SlideEngine | Hub + Player 两层 |
| 内容 | 文字/截图/代码幻灯片 | 模拟真实 UI 的组件 |
| 布局 | 单栏 | 三栏（步骤/模拟/信息） |
| 旁白 | 无 | 每步都有解说词 |
| 角色 | 无 | 角色徽章标识 |
| 焦点 | 无 | focus prop 高亮 |
| 动画 | 简单 fade | 方向感知 slide |
| 导航 | 基础翻页 | 步骤栏 + 快捷键 + 场景切换 |
| 数据 | 硬编码幻灯片 | TypeScript 声明式 |
| 组件复用 | 无 | 同一组件多焦点复用 |
