技术栈

一、后端

技术用途
Python 3.12 + Django 5Web 框架、ORM、Admin
Django REST FrameworkREST API、ViewSet、序列化、认证
django-fsm / django-fsm-log实例状态机 + 状态流转日志
django-filter列表筛选/搜索
drf-spectacularOpenAPI Schema 与 Swagger
django-simplejwtJWT 认证（人员 + 程序凭证）
SQLite（演示）/ PostgreSQL（生产）数据存储

二、前端

技术用途
Vue 3 + Vite工程框架与构建
Element Plus主 UI 组件库
Arco Design部分图表/看板组件
form-create（@form-create/element-ui）基于 Schema 的动态表单渲染
Pinia状态管理
ECharts数据可视化

三、流程设计器与部署

  • Beeflow：开源的流程设计器，产出树形 nodeConfig，前端做深度改造（节点类型映射、条件/网关转换、办理任务配置）。
  • Docker Compose：api + frontend 两个服务，本地/演示一键拉起。
  • 反向代理：Nginx 托管静态资源并转发 API，配置本地域名 *.workflow.orb.local。
