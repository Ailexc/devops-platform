提单预检与流程预演

一、四步提单

  1. 选择流程：从已发布流程中选择。
  2. 填写表单：基于 form-create 动态渲染，表单即 Schema。
  3. 审批路径预演：根据表单数据实时计算唯一审批路径（条件分支在此刻求值），左侧时间线 + 右侧节点详情，看这张单会经过哪些人。
  4. 提单预检：三块——基础校验（必填/范围/格式）、业务规则（命中拦截/警告）、办理节点 DryRun（预览自动执行的动作与入参）。

二、路径预演原理

用 compute_flow_path 对表单数据求值条件分支，纯计算不落库，把「提交后实际会经过哪些节点」算出来；与详情页「流程追踪」同源，保证口径一致。

三、办理节点 DryRun

对路径上的办理节点做「干跑」：按字段绑定构造入参 → 校验能力入参 Schema → 展示将执行的动作与入参，让你在提交前就知道「自动执行会发生什么」。

四、表单值回填

基础校验逐项回显当前填写的值（如「CPU 核数 = 32」，命中规则时高亮对应条件明细），把「为什么拦」讲清楚。
