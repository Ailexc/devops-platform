系统架构

本系统是一套流程驱动的业务自动化平台：通过可视化流程设计器编排审批链路与自动化动作，让「人工审批」与「系统自动执行」在同一张流程图上无缝衔接，并配套业务规则引擎、提单预检、能力编排等核心能力。

一、总体分层

层次说明关键技术
接入层Web 管理端、程序发起（OpenAPI）、飞书审批渠道JWT、X-App-Code / X-App-Key、多渠道
前端申请/审批/配置/管理全部交互Vue3、Vite、Element Plus、Arco、form-create、ECharts
API 层RESTful 接口，统一认证/鉴权/异常/幂等Django REST Framework
业务核心流程引擎、规则引擎、能力编排、预检预演、事件总线Django、django-fsm、自定义解释器
数据层流程定义/实例/任务/审批记录/能力作业SQLite（演示）/ PostgreSQL（生产）

二、核心组件

  • 流程设计器（Beeflow）：拖拽编排 发起/审批/抄送/条件/网关/办理/触发器 节点，产出树形 nodeConfig 定义。
  • 流程引擎：把树形定义归一化为 nodes + edges，驱动 启动 → 推进 → 完成 的完整生命周期。
  • 任务执行器：办理节点支持 人工办理 / 完全自动执行 / 自动执行+人工确认，串行/并行编排能力动作。
  • 业务规则引擎：结构化规则 AST，支持上下文指标（配额/预算/网络可达等）校验，预检拦截 + 提交复检。
  • 事件总线 & Webhook：流程/任务事件驱动外部集成。

三、关键数据流

提单(表单) → 规则预检(基础校验+业务规则+办理节点DryRun) → 发起实例
           → 引擎推进 → 审批任务(多用户/多渠道) / 自动办理(能力动作)
           → 实例完成 → 事件通知 → 可查询(我的申请/待办/已办/审批记录)

四、部署形态

Docker Compose 一键部署：api（Django 开发服务器 + SQLite）与 frontend（Nginx 托管 Vue 构建产物），演示环境零外部依赖即可运行。
