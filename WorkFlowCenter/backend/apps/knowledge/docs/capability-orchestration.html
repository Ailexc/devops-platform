能力编排与自动执行

一、能力注册

外部系统能力（创建主机、发送邮件、开通权限…）统一注册为 Capability，声明入参 Schema 与执行方式（同步/异步）。演示环境内置 Mock 能力，真实场景可替换为真实接口调用。

二、动作编排

办理节点的 taskConfig.actions 编排多个动作：

actions: [
  { key: act_create_host, capabilityCode: cmdb.create_host,
    fieldBindings: [{ capabilityField: hostname, source: form, formField: hostname }] },
  { key: act_send_notify, capabilityCode: mail.send,
    fieldBindings: [{ capabilityField: to, source: form, formField: email },
                    { capabilityField: subject, source: constant, constant: '创建完成通知' }] },
]

字段绑定支持三种来源：表单字段、常量、前序动作输出。

三、执行模式

  • 串行：动作逐个执行，前序输出可供后续绑定。
  • 并行：动作同时创建执行，全部完成后统一判定。
  • 异常处理：动作失败 → 节点标记异常，转人工处理（支持重跑失败动作），并生成执行日志。

四、执行日志

每个动作记录完整时间线日志（时间/级别/消息），详情页流程追踪可逐节点查看入参、出参与日志，做到「自动化也可审计、可排障」。
